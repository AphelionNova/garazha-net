## Выбранное размещение

App Platform → Frontend → Next.js → включить SSR (платформа переводит приложение в backend-режим). Отдельные VPS, Dockerfile, nginx и PM2 проекту не нужны.
Предварительно минимальная конфигурация 1 vCPU / 1 ГБ RAM; достаточность памяти подтвердить сборкой в Timeweb. При OOM рассмотреть 2 ГБ после согласования цены, не отключать TypeScript и не переделывать сайт в static.
Публичный прайс с 15.12.2025 указывает 510 руб./мес. для Backend App 1/1/15; это ориентир, не подтверждённая цена текущего аккаунта. Итоговую стоимость, IPv4 и другие начисления проверить в панели перед созданием. Более дешёвый frontend/static не сохраняет оба API. Любую оплату и создание платного ресурса подтверждает владелец.

Только после приёмки технического адреса обсудить конкретный собственный домен. garazha-net.vercel.app принадлежит Vercel и не переносится как собственный домен.

После включения автодеплоя каждый push в production-ветку должен запускать пересборку; проверить это первым согласованным обновлением. Для отката к версии кода использовать предыдущий успешный deployment или git revert, без force push.
Для инфраструктурного отката восстановить прежние DNS-записи и, если менялся, адрес webhook YCLIENTS. Vercel deployment и доменную привязку сохранять до завершения миграции. До смены DNS откат не нужен: рабочий сайт продолжает обслуживать Vercel.
