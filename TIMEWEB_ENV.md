# Переменные Timeweb Cloud

Секретные значения хранятся только в настройках приложения Timeweb. Не добавлять `.env.local` в Git.

- `TELEGRAM_BOT_TOKEN` — серверный токен существующего Telegram-бота; нужен обработчикам записи на ремонт и webhook YCLIENTS. Обязателен в runtime. Перенести из локальной конфигурации через защищённое поле панели, без публикации в чате.
- `TELEGRAM_CHAT_ID` — идентификатор существующего чата получателя уведомлений; обязателен в runtime.
- `SITE_URL` — полный публичный origin приложения, с протоколом HTTPS, без пути. Для тестирования указать фактический технический адрес Timeweb после его получения. Используется сервером для проверки Origin формы за HTTPS-прокси. При подключении собственного домена заменить одной настройкой и перезапустить приложение. Это не секрет. Без значения сохраняется прежняя проверка по адресу запроса и Host. Неверное значение блокирует отправку формы.

Не использовать префикс NEXT_PUBLIC_ для секретов. Значения не нужны для сборки страниц.
Служебный `VERCEL_OIDC_TOKEN` не используется кодом приложения и не переносится в Timeweb.
`PORT` при необходимости задаётся платформой и читается стандартным `next start`; не помещать его в `.env.local` для настройки процесса запуска.
